# Mobility Pass — public source note

The approved bilingual one-pager is the public source used for the first Mobility Pass surface.

It supports the following statements:

- Mobility Pass is identified as the first pilot for 2026.
- The stated aim is to lend 30-day SL public transport cards with a 25% co-pay.
- Crowdfunded donations are described as covering the remaining cost.
- The source states SEK 795 as one pass-month.
- The stated focus is single mothers and others with urgent mobility needs connected to work, study and care.

The source does **not** establish, by itself:

- that live delivery has begun;
- current participant numbers;
- current funding level;
- whether the stated price remains current;
- measured outcomes or downstream effects.

The public interface therefore labels the item conservatively as `source-described-pilot` and does not infer operational facts beyond the source.
