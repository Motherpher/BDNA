## Translation rule

The website may shorten, layer and visualise these materials. It must not silently replace source concepts with conventional NGO vocabulary when that changes meaning. In particular, `beneficiary`, `empowerment`, `impact`, `success story` and `charity` require contextual scrutiny before use.
