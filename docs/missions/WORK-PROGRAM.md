# BDNA Web Platform — work programme

## Status vocabulary

- **DONE** — repository-side scope implemented and evidence exists.
- **PARTIAL** — architecture exists, but a source, human decision or external dependency remains.
- **MOCK-DONE** — external deployment gate administratively simulated; not actually executed.
- **OPEN** — not yet completed.

## Development sequence after this baseline

The site should now evolve through bounded improvements rather than architecture replacement:

1. Resolve controlled Swedish terminology and approved deep translations.
2. Use BDNA Lab for bounded visual explorations against the canonical module/source model.
3. Add further Asset Keys or cases only when source-approved public material exists.
4. Replay all Vercel mock gates when credits return.
5. Merge to `main` only after the Director accepts either real deployment evidence or an explicit continued mock-release exception.
