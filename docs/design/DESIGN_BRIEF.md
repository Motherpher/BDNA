# Design brief — source-first

## Objective

Create a public digital interface that feels like durable infrastructure rather than a campaign microsite, institutional NGO template or identity-brand showcase.

## Design behaviour

The Blackprint is layered and recursive. The interface should therefore support:

- multiple entry points;
- strong conceptual navigation;
- progressive disclosure;
- diagrams for relationships rather than decorative diagrams;
- visible distinctions between mission, diagnostic logic, operational instruments and reference material;
- deep pages that remain readable without forcing users through a linear funnel.

## What the design should avoid

- conventional charity aesthetics;
- transformation/saviour storytelling;
- testimonial-first architecture;
- overexposure of individuals as proof of legitimacy;
- generic DEI iconography;
- visual language that suggests BDNA owns or directs user outcomes;
- excessive brand activity that competes with operational work.

## Priority visual systems to design

1. BDNA system map: Foundation ↔ Fund ↔ Asset Keys ↔ Fonio.
2. Life & Opportunity Pivot Map.
3. Boundary permeability / access friction visual grammar.
4. Asset Key anatomy.
5. Impact Area constellation.
6. Passing-forward logic.
7. Stakeholder access ecology.

## Current scaffold

The existing CSS is deliberately provisional. It establishes rhythm and responsive structure only. Lovable/design work should replace it with an approved system without changing the source model casually.
