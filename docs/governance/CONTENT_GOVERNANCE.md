# Content governance

## Authority

The Blackprint is the conceptual authority for the first public build. Interface copy is derivative, not autonomous.

## Change classes

### Class A — presentation
Typography, layout, interaction, illustration and shortening that do not change meaning.
Can move through normal design/development review.

### Class B — interpretive copy
New summaries, explanatory copy, diagrams, labels or page structures that interpret a source concept.
Requires source check before merge.

### Class C — conceptual / policy
Changes to mission, Logic of Access, component roles, ethics, definitions, governance or evaluation doctrine.
Requires explicit human decision and source update before the site changes.

## Trace rule

Any Class B or C change should identify its source section in the pull request.

## Narrative discipline

The Blackprint treats narrative coherence as an asset and explicitly warns against overexposure, premature storytelling and representation that consumes operational resources. The site should therefore explain the infrastructure before trying to produce emotional proof of it.
